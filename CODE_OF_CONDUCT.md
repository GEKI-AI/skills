# Code of Conduct

We want this project to be a friendly place to work on, for everyone.

## Our standard

- Be kind and patient. Assume good intent.
- Be respectful of different views and levels of experience.
- Give feedback on the work, not the person. Accept feedback the same way.
- Keep to the topic of the project in issues and pull requests.

Not acceptable: harassment, insults, discrimination, personal attacks, publishing private information about others, and anything else that makes people feel unwelcome.

## Enforcement

Maintainers may edit or remove comments, close issues and pull requests, and block people who do not follow this code. Report a problem to conduct@geki.ai. We keep reports private and handle them fairly.

This code applies in the project's spaces on GitHub and when someone represents the project in public. It is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
